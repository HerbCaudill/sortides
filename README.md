# Sortides

A static collection of outings. Run `pnpm install` and `pnpm dev` to start the site. The map loads styles and tiles from OpenFreeMap over the network; the app itself has no backend.

Edit `src/data/outings.json` to change the outings. `src/data/outings.ts` validates the data at startup. The list combines saved places, researched city visits and illustrative sample events. Museum visitor information was checked against the linked official pages on 28 October 2026; follow those links for current hours, prices and exhibition access. Coordinates are approximate.

Exhibitions are specific temporary shows, with `startsOn` and `endsOn` dates and an exhibition-page link. The day-trip list shows them only during their run, using the current date in Catalonia, and displays their closing dates. General museum permanent collections are not standing recommendations; distinctive specialist museums can be. Exhibition picks were checked on 28 October 2026.

The mini's Windows scheduled task **Sortides daily refresh** runs at 08:00 local time (Europe/Madrid) every day, including while Herb is signed out. It invokes headless `codex exec --ephemeral` through `scripts/events/runDailyRefresh.ps1`, following `scripts/events/dailyRefresh.prompt.md`: fetch the Barcelona agenda, research official music, film and exhibition calendars, judge new candidates, validate selections and publish to main. T3 does not need to be running, and the previous T3 schedule is disabled. The job uses Herb's saved Codex CLI login, GitHub authentication, installed pnpm dependencies and network access. It runs with full filesystem/network access and no approval prompts for the authorized publishing workflow. Vercel publishes main automatically. Source failures are reported and coverage can be partial.

Register or update the task from an elevated PowerShell with `pwsh -NoProfile -File scripts/events/registerDailyRefresh.ps1`. It catches up after a missed start, ignores overlapping invocations, and has no fixed runtime limit. Logs and final summaries are timestamped under `%LOCALAPPDATA%/sortides/refresh`; `latest.json` records the last exit code and log paths. The source report remains in `.events/YYYY-MM-DD-report.json`. Use `Disable-ScheduledTask -TaskName 'Sortides daily refresh'` to pause it. To verify the scheduled account without refreshing or publishing, register with `-Check`, start the task, inspect the check log for `SORTIDES_RUNNER_OK`, then register again without `-Check` to restore the daily workflow.

Run `pnpm events:fetch` to save unjudged Barcelona candidates in `.events/YYYY-MM-DD-candidates.json`. Write decisions as `{id, outing}` or `{id, reason}` entries, then run `pnpm events:apply <decisions.json>`. Apply validates the whole batch, rejects unlinked/out-of-range picks, preserves standing places, prunes expired events and updates `data/events/judged.json`. It does not commit or push itself. Per-source reports and intermediate files remain under ignored `.events/`; selection history is versioned. Check the runner's summary and source report for source errors and publishing failures.

Run `pnpm test`, `pnpm build`, and `pnpm exec playwright test` to check the app. Install the Playwright browsers with `pnpm exec playwright install chromium webkit` if needed.

For each day trip, `bases` lists the eligible bases and an estimated `driveMinutes` from each. Include both bases when both are within 120 minutes. If neither is within 120 minutes, include only the nearer base. Drive times are approximate; replace estimates with researched values when available. Date nights must have a date and a Music or Movies kind. `sourceList` and `mapsUrl` are optional fields for future saved-list imports.

Outings can include an optional `photo` with `url`, `alt`, `credit`, `sourceUrl`, `license`, and `licenseUrl`. Use a local `/photos/` image or an image URL. Details show photos with source and license links; missing or failed images leave the detail text intact. The initial Wikimedia Commons photos are resized and converted to WebP in `public/photos/`, with attribution stored on each outing. Keep those credits when replacing or adding photos.
